### Evening review corrections

- Active LCD/canvas now has portrait **480×640** ratio; actual 128 mm × 171 mm physical specification remains a reference pending measured photographs.
- ENTER is separate from TrackPad. Browser-only rotary helpers ± are outside the machine facade and explicitly labeled as training affordances.
- DUAL header now reads LF/HF; the not-yet-correct ZOOM view explicitly says F0 rather than teaching an invented manufacturer header.
- POWER captures real pressed duration in replay even when sim time is paused. FUNC uses a **provisional 650 ms** threshold that is not derived from the manual. Both require real-device gesture acceptance for F1.
- VRM input in sonar views now changes an illustrative horizontal marker and depth readout; NAV modes do not permit VRM movement. Vertical increment and marker styling are not yet accepted from hardware.
